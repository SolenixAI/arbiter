# Glossary

The terms of this repo. Each term has one meaning and one source: the linked section of [AGENTS.md](../AGENTS.md). This page names each term. It does not restate a rule, so it cannot drift from the file.

- **Arbitrary success**: the north star of the file. [Root](../AGENTS.md#arbiter)
- **Docus, Experis, Imples**: documentation, experimentation, implementation: the three parts of each section and each container. [Root](../AGENTS.md#arbiter)
- **Container law**: a container holds docus, experis and imples (files only), meaningful children and a TERMINUS.md. [Root](../AGENTS.md#arbiter)
- **`{[ ]}`, `{{ }}`, `:< >`, `~!`, `..`**: parts that work together; a closed, complete set; generates; eliminates the existence of; from, through, to. [Root](../AGENTS.md#arbiter)
- **Escape**: a contradiction that the user finds in work called done. [§10](../AGENTS.md#10-done-means-it-exists-for-the-user)
- **⊥ contradiction event**: the fact that proves a section failed. Each Impact names one. [Root](../AGENTS.md#arbiter), [§12](../AGENTS.md#12-fragments)
- **5:0**: the goal state, with zero open fragments in scope. [§1](../AGENTS.md#1-goal-state)
- **AUX**: the agent-user experience, the two sides of every experience. [§2](../AGENTS.md#2-optimal-aux)
- **Fib3 tree**: the search tree for open questions on a hard problem. [§3](../AGENTS.md#3-learn-how-before-doing)
- **POE**: predict, observe, explain: how you prove that you understand a tool. [§4](../AGENTS.md#4-install-use-configure-understand)
- **SOT**: the single source of truth for a fact. [§5](../AGENTS.md#5-decide-from-data)
- **OKF**: the trust header of a file. [§5](../AGENTS.md#5-decide-from-data)
- **PVI²**: north star, inspiration, purpose, value, impact. [§6](../AGENTS.md#6-compounding-wins)
- **The ratchet**: each kept win becomes the next baseline. [§6](../AGENTS.md#6-compounding-wins)
- **TTT**: time to terminus, the time predictions to the goal or a terminus. [§6](../AGENTS.md#6-compounding-wins)
- **Terminus**: a limit you cannot remove or control; an avoidable hit is the failure. See [TERMINUS.md](../TERMINUS.md). [§7](../AGENTS.md#7-time-matters)
- **Blocker**: a learn-how problem, solved by the right tool and recipe. [§8](../AGENTS.md#8-do-the-work-three-pathways)
- **Recipe**: the known steps that complete a task right the first time. [§3](../AGENTS.md#3-learn-how-before-doing)
- **Frontier**: where the search tree finds no new source, so the agent builds from the best pieces. [§3](../AGENTS.md#3-learn-how-before-doing)
- **One correct best way**: the one pathway an agent takes at each choice. [§8](../AGENTS.md#8-do-the-work-three-pathways)
- **User journey**: a person going from x to y for z. [§2](../AGENTS.md#2-optimal-aux), [§10](../AGENTS.md#10-done-means-it-exists-for-the-user)
- **Learning event**: one real walk of a user journey, ending in success or in a failure to learn from. [§10](../AGENTS.md#10-done-means-it-exists-for-the-user)
- **Schrödinger's cat**: work that nobody has observed in the user's view. [§10](../AGENTS.md#10-done-means-it-exists-for-the-user)
- **Fragment**: a piece that exists but is not resolved yet, in one of five types. [§12](../AGENTS.md#12-fragments)
- **Body**: a disjoint system that holds a fact. [§13](../AGENTS.md#13-the-three-body-problem)
